Security

What GKOF does to stay playable, and how to report a problem.

Anti-cheat

Modified headsets

Rooted or modified headsets used to bypass movement tracking won't be allowed into ranked matches. Detection is still being tuned — a false flag (a dropped connection read as tampering) is possible during development. Report it on the Discord if it happens to you.

Report

A security issue

For a technical vulnerability — not a gameplay bug — contact the team privately on Discord rather than posting it publicly, until a fix is ready.
